# Cline Configuration for VibeCheck

## Plan Mode
Uses Llama 3.3 for analysis and planning
- Model: llama3.3 (local via Ollama)
- Purpose: Complex reasoning, architecture decisions, planning

## Act Mode
Uses Qwen for implementation
- Model: qwen2.5-coder:32b (local via Ollama)
- Purpose: Code generation, file edits, implementation

## Ollama Configuration
Local Ollama provider endpoint: http://localhost:11434

Both models must be pulled locally:
```bash
ollama pull llama3.3
ollama pull qwen2.5-coder:32b
```

## Usage
- Use plan mode for: architecture decisions, debugging complex issues, planning large refactors
- Use act mode for: quick implementations, file edits, straightforward coding tasks
