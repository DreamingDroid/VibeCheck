# Project VibeCheck: Implementation Context
- **Name:** VibeCheck (The catchy successor to 'Pulse')
- **Goal:** AI WhatsApp Concierge for city events (Vizag/Global).
- **Architecture:** RAG-first using Node.js, LangGraph, and PostgreSQL (pgvector).
- **Infrastructure:** Docker Compose (Postgres 17, Ollama with mxbai-embed-large, Appsmith for Admin).
- **Status:** Architecture finalized. Moving to implementation in Antigravity IDE.
