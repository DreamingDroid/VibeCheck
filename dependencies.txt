======================================================
               VIBECHECK DEPENDENCIES
======================================================

This file contains the list of all dependencies required 
to run both the Backend (server) and Frontend (web).

------------------------------------------------------
HOW TO INSTALL ALL DEPENDENCIES
------------------------------------------------------
To install all required libraries after cloning the 
codebase, the easiest way is to use npm directly since
all these dependencies are already recorded in their
respective package.json files.

Run the following commands in your terminal from the 
root of the project:

# Install Backend Dependencies
cd server
npm install

# Install Frontend Dependencies
cd ../web
npm install

(Note: If you run this file as a batch script by renaming
it to dependencies.bat, it will execute the commands above.)
