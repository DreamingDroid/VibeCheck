# VibeCheck Agent Configuration

This agent is configured for the VibeCheck project with dual-model support.

## Available Models

- **Model**: llama3.3
- **Provider**: Ollama (local)
- **Use Case**: Architecture decisions, complex debugging, planning

### Act Mode (Implementation)
- **Model**: qwen2.5-coder:32b
- **Provider**: Ollama (local)
- **Use Case**: Code generation, file modifications, implementation

- **Frontend**: Next.js (web/)
- **Backend**: Express + TypeScript (server/)

- **Services**: Discord integration, WhatsApp integration, RAG system

## Tool Configuration

All tools are enabled:
- File read/write access
- Terminal command execution
- Git operations
- Web access (for documentation)

## Local Development

Ensure Ollama is running locally with models available:
```bash
ollama serve
```

Pull required models:
```bash
ollama pull llama3.3
ollama pull qwen2.5-coder:32b
```
